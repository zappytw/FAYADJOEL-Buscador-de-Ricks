## Overview

A small, focused frontend project that consumes the [Rick and Morty API](https://rickandmortyapi.com/) to search and display characters from the show. Built as an exercise in real-world API consumption, error handling, and dynamic DOM rendering.

## Features

- Search any character by name
- Display character image, status, species, and origin
- Graceful handling of empty results and network errors
- Fully responsive layout

## Stack

- HTML5 · CSS3 · JavaScript ES6+
- [Rick and Morty API](https://rickandmortyapi.com/) — REST, no auth required

## Run locally

```bash
git clone https://github.com/zappytw/FAYADJOEL-Buscador-de-Ricks.git
cd FAYADJOEL-Buscador-de-Ricks
```

Open `index.html`.
